# Attribution and licence notes

- **Parking data:** contains data from Brighton & Hove City Council (the ArcGIS FeatureServer behind their parking map).
  The service states no licence, so this project treats it as **personal use**, fetches it politely (once a week) and credits the council.
  It is not offered as an API or a product. If the council asks for it to be removed, it will be.
- **Traffic Regulation Orders:** used only to cross-check hours (Brighton & Hove Various Controlled Parking Zones Consolidation Order 2024, as amended), published via https://tro.tpt.gov.uk/brighton-and-hove/.
- **Basemap:** © OpenStreetMap contributors, served by OpenFreeMap.
- **Geocoding:** postcodes.io (postcodes) and Nominatim / OpenStreetMap (place names), each used within their usage policies.
- **Map library:** MapLibre GL JS (BSD-3-Clause).

**Check the signs.** This is a planning aid, not legal advice. Suspensions, temporary and experimental orders, roadworks, event days and
anything the council has changed since the last data refresh are not reflected. The signs on the street are what count.
